# AI Inbox implementation contract
Public code; private single-owner data. Next.js App Router + TypeScript + React + Tailwind CSS + shadcn/ui; Bun package manager, Next production Node runtime; Drizzle + better-sqlite3 persistent SQLite, FTS5. No hosted dependency required. Never commit private hostnames/IPs, content, credential references, webhook URLs or runtime data. DB path INBOX_DATA_DIR/inbox.sqlite; media directory INBOX_DATA_DIR/media.

API contract: GET /api/items?view=inbox|unread|archive|all&q=&kind=briefing|alert&cursor=&limit= returns {items: InboxItem[],nextCursor:string|null,counts:{inbox,unread,archive},total:number}; GET /api/items/:id returns {item}; PATCH /api/items/:id accepts {read?:boolean,archived?:boolean}, returns {item}; GET /api/items/:id/audio supports Range; GET /api/health returns non-sensitive readiness. InboxItem {id,title,kind:'briefing'|'alert',edition:'morning'|'evening'|null,publishedAt:string,body:string,summary:string,sources:Array<{title,url}>,audioAvailable:boolean,audioDuration:number|null,readAt:string|null,archivedAt:string|null,tags:string[]}.

Schema uses unique externalId for ingestion idempotency, preserved read/archive state on reimport. Source markdown sanitized using react-markdown, no raw HTML. Input zod validated. Origin/same-site checks for writes, parametrized FTS. Private network binding via systemd env; no public listen. Persistent state outside releases. API locally available to ingestion CLI, no remote unauthenticated ingestion endpoint. Mobile first, keyboard accessible, focus, empty/loading/error/retry states, no fake chat UI.

Ownership: frontend agent owns src/app/page.tsx, layout.tsx, globals.css, src/components/**, frontend configuration + initial package.json. Backend agent owns src/server/**, src/app/api/**, src/lib/contracts.ts, scripts/import.ts + backend tests, drizzle config. Ops agent owns deploy/**, docs/operations.md, .github/**, scripts/deploy*; does not deploy until parent integrates. Parent owns README, AGENTS, research, automations, git/repo + final deployment. Backend/ops coordinate package edits after frontend creates file; no git commits by children, no nested subagents. Tests verify meaningful behavior. API response shape is fixed above.
